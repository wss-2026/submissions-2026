# wss-2026 / submissions

웹서버보안프로그래밍 과제·팀프로젝트 **제출 전용** 레포입니다.

이 레포에는 여러분의 소스코드를 올리지 않습니다. 여러분의 코드는 어디에 있어도 상관없습니다
(개인 GitHub 계정, 별도 조직 등 자유). 이 레포에는 **"내 코드가 어디에 있고, 어떤 커밋을,
어떤 주소로 배포했는지"** 정보만 한 줄(JSON 파일 하나)로 제출합니다.

## 제출 방법

1. 이 레포를 본인 계정으로 **Fork** 합니다.
2. `submissions/weekNN/` 폴더 아래에 `본인학번.json` 파일을 새로 만듭니다.
   (팀 프로젝트는 `submissions/team/팀이름.json`)
3. 아래 형식에 맞춰 내용을 채웁니다.

```json
{
  "student_id": "20231234",
  "name": "홍길동",
  "repo_url": "https://github.com/hong/websecprog-week03",
  "commit_sha": "a1b2c3d4e5f6...",
  "deploy_url": "https://hong-week03.vercel.app"
}
```

- `repo_url`: 본인 코드가 있는 GitHub 레포 주소 (public 권장 — private이면 아래 "비공개 레포 안내" 참고)
- `commit_sha`: 채점받고 싶은 **정확한 커밋의 전체 SHA**. `git log`로 확인하세요.
  (매번 최신 커밋이 아니라, "이 시점 기준으로 채점해주세요"라는 의미입니다. 나중에 더 고치고
  다시 채점받고 싶으면 새 커밋 SHA로 다시 제출하면 됩니다.)
- `deploy_url`: Vercel 등에 실제 배포된 주소

4. 이 레포로 **Pull Request**를 보냅니다.
5. PR을 올리면 자동으로 형식 검증이 돕니다 (`validate` 체크). 초록불(✅)이 뜨면 정상입니다.
6. PR이 `main`에 merge되면 자동으로 채점이 시작됩니다. 결과는 조교/강사가 확인하며,
   필요 시 PR 코멘트로 결과가 공유됩니다.

## 제출 시각 = 이 PR을 올린 시각

마감 시각 판정은 **여러분의 원본 레포에 있는 커밋 시각이 아니라, 이 레포에 PR을 올린 시각**을
기준으로 합니다. (원본 레포의 커밋 시각은 얼마든지 조작 가능하기 때문입니다.) 마감 직전에
급하게 제출하지 말고 여유 있게 PR을 올리세요.

## 비공개(private) 레포로 제출하는 경우

`repo_url`이 private 레포라면, 채점 봇 계정이 코드를 읽을 수 있도록 **Collaborator로
초대**해야 합니다. 초대할 계정 이름은 강의 공지를 참고하세요 (예: `wss-2026-grader-bot`).
초대하지 않으면 자동채점이 "레포 접근 실패"로 처리됩니다.

## 자주 하는 실수

- `commit_sha`를 짧게 쓰거나(`a1b2c3`) 브랜치 이름을 적는 경우 → 반드시 전체 SHA(40자)를 사용하세요.
- `deploy_url`에 `http://`를 쓰는 경우 → 반드시 `https://`.
- 파일 하나에 여러 명 정보를 합쳐서 올리는 경우 → 1인(팀) = 1 JSON 파일.
